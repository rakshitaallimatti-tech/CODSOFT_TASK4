# Cloud Backup and Restore System

## Description
A Python application to create backups of files and restore them when needed.

## Features
- Create file backups
- View backup history
- Restore backed-up files
- Store backups in separate folders

## Technologies Used
- Python
- os module
- shutil module

## How to Run
Run the task4.py file using Python.

## Project Status
Basic local backup and restore prototype.
